# Badge

Etiqueta compacta para status e metadados. Variante `success` (verde) é usada para destacar desconto; `secondary`/`outline` para tipo e modalidade do imóvel.

```tsx
<Badge variant="success">90% OFF</Badge>
<Badge variant="secondary">Apartamento</Badge>
<Badge variant="outline">Leilão SFI</Badge>
```

# Sheet

Painel deslizante lateral (radix Dialog). Compõe com `SheetTrigger`, `SheetContent`, `SheetTitle` e `SheetClose`. Usado para os filtros no mobile.

```tsx
<Sheet>
  <SheetTrigger asChild><Button>Filtros</Button></SheetTrigger>
  <SheetContent><SheetTitle>Filtros</SheetTitle>...</SheetContent>
</Sheet>
```
